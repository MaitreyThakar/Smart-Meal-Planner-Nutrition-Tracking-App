# Smart Meal Planner & Nutrition Tracking App

## Overview
The Smart Meal Planner & Nutrition Tracking App is designed to help users plan their daily meals, track calorie intake, monitor nutrition goals, and generate insights into their eating habits. This app is particularly beneficial for students and working professionals who struggle to maintain a balanced diet due to a lack of structured meal planning and awareness of their nutritional intake.

## Features
- **Meal Planning**: Create daily meal plans with options for breakfast, lunch, dinner, and snacks.
- **Nutrition Tracking**: Track calories consumed and basic nutrients (protein, carbs, fats).
- **Goal Setting**: Set daily nutrition goals for calories and optional nutrient targets.
- **Progress Analytics**: Visualize daily calorie intake versus goals, weekly trends, and goal achievement percentages.
- **Food Database**: Access a basic list of food items with default calorie values and the ability to enter custom food items.
- **Search & Filter**: Easily search for food items and filter meal entries by date and meal type.
- **Offline Functionality**: Log meals and track nutrition without internet connectivity, with data synchronization when online.

## Technical Specifications
- **Framework**: Flutter
- **State Management**: Provider / Riverpod / Bloc
- **Local Storage**: Hive / SQLite
- **Backend**: Optional Firebase / REST API
- **Architecture**: Modular architecture with clean and maintainable code

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/smart_meal_planner.git
   ```
2. Navigate to the project directory:
   ```
   cd smart_meal_planner
   ```
3. Install dependencies:
   ```
   flutter pub get
   ```
4. Run the app:
   ```
   flutter run
   ```

## Usage
- Open the app and navigate to the Meal Planning screen to create your daily meal plan.
- Use the Food Entry screen to log food items and track your calorie intake.
- Check the Daily Tracking screen for an overview of your nutrition.
- Visit the Analytics Dashboard for insights into your eating habits and progress towards your goals.
- Utilize the Search & Filter screen to find specific food items or meal entries.
